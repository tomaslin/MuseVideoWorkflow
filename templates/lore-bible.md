# Lore bible template

One file per project, `projects/<slug>/lore-bible.md`, when the
project uses invented or folkloric material — and for realistic
projects, the equivalent world-rules document (house rules, object
rules, character rules).

Rules are stated as rules, not as mood. Each rule must be checkable
in a shot: a reviewer must be able to say "this shot breaks rule 4"
or "this shot exercises rule 4." End with a violations checklist.

Sections: the world, the people/sects, the locations, the creatures
or objects and their rules, cause and effect (what causes what),
and violations.
