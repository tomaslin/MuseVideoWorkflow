# Chapter 06: Storyboard & Animatic

**Billable unit:** Billable unit: one panel per shot, plus one animatic

**Tension function:** Tension: drawn before it is generated — the cheapest place to see if tension works.

Inputs: script, breakdown. Outputs: storyboard panels (image, caption, camera, action, tension value, sound cue), animatic (panels timed to the script, with temp voice/music). Gates: one panel per shot, panel count = shot count, tension values form the intended curve, no panel without a camera move and a sound cue. Cost drivers: panel images (1 per shot, up to 4 per request for images). Visual remedy: panels are viewable in the studio UI storyboard view and on GitHub Pages — see apps/studio/storyboard.html. Storyboard mapping: this IS the storyboard chapter. A storyboard that does not show tension rising and falling is a list of pictures, not a film.
