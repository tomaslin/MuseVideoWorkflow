# Chapter 10: Generation: Images, Clips & Takes

**Billable unit:** Billable unit: one batch (<=6 clips) or one take set

**Tension function:** Tension: generated, not just planned — this is where drift is fought.

Inputs: prompt packets, reference images. Outputs: clips per shot with prompt, prompt hash, seed, model, model version, take number, critique status. Gates: locked blocks verbatim (validator), reference image supplied, take recorded, no clip marked locked without critique resolution or waiver. Cost drivers: clips per batch, redos per outlier, reference images. Storyboard mapping: each generated clip replaces its panel; the panel stays in history so you can see what was intended vs. what was made.
