# Chapter 04: Script & Dialogue

**Billable unit:** Billable unit: one complete, performable script

**Tension function:** Tension: rises beat by beat; every beat changes power, knowledge, or feeling.

Inputs: outline. Outputs: full script, audio script (dialogue/narration separated), scene directions, production notes, source claims. Gates: no placeholders, no teasers, dialogue does one of reveal/advance/change, negation/numbers/dates/uncertainty preserved exactly. Cost drivers: script length in beats (10s per beat); a 90-minute feature is 540 beats — see pipeline/movie.py estimate before committing to a feature. Storyboard mapping: each beat becomes one storyboard panel; a beat with no visual action has no panel and must be rewritten.
