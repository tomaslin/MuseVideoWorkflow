# Chapter 08: Look, Color Script & Grading Intent

**Billable unit:** Billable unit: one color script + grading intent

**Tension function:** Tension: color follows tension — cold and desaturated at the low point, warm or saturated at release, by rule, not by accident.

Inputs: look bible, storyboard. Outputs: color script (palette per sequence, with a rule for how it changes with tension), show LUT intent, grading notes per sequence, reference stills. Gates: color script exists before generation; a sequence without a color rule is not generated. Cost drivers: grading time, LUT creation, color redos after picture lock. Storyboard mapping: each panel carries its sequence palette; panels side by side should show the color arc.
