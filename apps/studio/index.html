MuseVideo Studio

Prompt first. Idea to video, with every artifact visible, editable, and versioned.

Trigger in chat: video idea: <your idea> — this UI is the same pipeline, driven from here.

Editing never overwrites history. A variant keeps the original, records its parent, the change prompt, and a new seed — an alternate reality of the same video, not a replacement.

State machine

Variants (alternate realities)

    History (append-only)

      Gap fixes (built in)

      • 10-second clip limit: chain shots with ffmpeg concat + xfade, then minterpolate for smoother motion. See docs/gaps-and-fixes.md and scripts/chain-clips.sh.
      • Sound: video clips carry mood sound only. Dialogue, music, and SFX are separate stems, mixed with amix, stretched with atempo, looped SFX with -stream_loop. See scripts/mix-audio.sh.
      • No lip-sync promise: voice is a separate stem, captioned from the audio script. Never claim sync the tool cannot guarantee.

      Determinism: seed = hash(idea + look + character). Same seed, same plan. Prompt hash per shot is recorded in the manifest. Model, model version, and clip file are recorded per clip when generation runs — a plan without those fields is not a shipped video.

      Final video lands in projects/<slug>/final/. See the repo README for the GitHub binary check-in route.
